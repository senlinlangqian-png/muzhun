使用方法
  1. 选择视频，或先打开合成示例。
  2. 点击字幕，试听本句；采用纠词建议或保留原词。
  3. 保存修改，检查字幕位置后标记已复核。
  4. 重复术语用“批量改词”先预览，再应用；保存后可撤销。
  5. 导出视频，或下载可编辑字幕。
示例与自动判断
合成示例含预设错词。题材按关键词判断，纠词参考画面文字，位置按抽样画面更新。复核状态由人标记；改动文字、时间或位置会取消对应记录。SRT 保留文字和时间，ASS 还保留位置。

  
在 Agent 中使用
双击项目里的 Install-Skill.cmd，选择自己的 Agent。也可运行：
python scripts/setup.py --agent deepseek
DeepSeek Harness 输入 /muzhun-subtitles。Codex、Claude Code、Cursor 分别把 Agent 参数改成 codex、claude、cursor。Codex 使用 $muzhun-subtitles。
Agent 需要能读写本机文件并执行 Python。安装与朋友试用步骤见项目 docs/friend-test.md。

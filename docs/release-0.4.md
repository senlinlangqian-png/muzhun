# 幕准 0.4.1：开源测试版说明

幕准给教程和游戏教学视频核对专业词，并让字幕避开正在讲解的区域。它将同时间画面证据、术语修正和字幕占位联合处理，保留可编辑结果和人工确认。0.3 的句内换位机制继续保留。

0.4 主要解决别人第一次安装和使用的问题：独立于 Codex 内部运行时的启动器、网页环境检查、端口占用处理、跨平台 Skill 安装、版本化发布文件和校验和。它没有新增通用语义理解模型。

0.4.1 简化上传与编辑页面，去掉装饰性口号和重复说明，将高级信息折叠；提供第一次上传 GitHub 的网页操作步骤。

## 公开提供的文件

- `muzhun-0.4.1-source.zip`：完整源码、网页、Skill、合成示例、测试和启动脚本。需要 Python，首次安装依赖需联网。
- `muzhun-subtitles-skill-0.4.1.zip`：仅 Skill；需另装幕准处理环境。
- `muzhun-0.4.1-py3-none-any.whl`：给熟悉 Python 的用户安装，引擎与网页资源均在包内。示例和 Skill 另在源码包内。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验和。

普通用户先看 quickstart.md；Codex 用户完成环境安装后再装 Skill。当前是源码测试版，尚未提供免 Python 安装包或公网视频处理服务。

## 验证与反馈

本次 74 项自动检查与新目录安装验证见 [testing.md](testing.md)。源码 ZIP 在同一台 Windows 电脑的新目录实际创建环境、安装 Skill，并完成 SRT 视频交付；这不能替代另一台电脑测试。跨平台 CI 配置不等于已通过远程 CI，其他真实设备和真实视频效果仍待反馈。

首批建议邀请 3–5 人，每人测试一段自己的短片，记录是否成功启动、是否导出、误改、遮挡、修改耗时和再使用意愿。用于展示的数据应区分合成演示与真实用户反馈。

## 上传 GitHub 时

只把这个 `muzhun` 项目作为仓库根目录，避免混入父目录的旧选题项目。发布 README、LICENSE、src、skills、scripts、tests、docs、examples 与 .github；`.gitignore` 排除虚拟环境、模型、输出、本机路径记录和生成包。发布包放到 GitHub Release 附件。

先作为开源测试版公开；得到另一台电脑的安装记录和真实视频反馈后再扩大宣传。源码中的安装教程、贡献入口和示例已备好；仓库创建、公开可见性和 Release 发布需要在选定的 GitHub 仓库实际执行。准备文件不等于已经上传。

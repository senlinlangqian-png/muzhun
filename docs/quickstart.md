# 第一次使用幕准 0.7.0

这是本地视频与歌词字幕工具，附带给本地 Agent 使用的 Skill。网页在你的电脑运行；字幕引擎不用购买域名、不用 API Key。源码测试版需要先安装 Python，尚不是免安装 EXE。

制作 LRC，或配合 DeepSeek Harness / Claude Code / Cursor 使用，见 [朋友试用步骤](friend-test.md)。

## Windows

1. 安装 64 位 Python 3.12，安装时勾选 Add python.exe to PATH。Python 官方下载页：https://www.python.org/downloads/windows/ 。
2. 下载源码 ZIP，解压整个 `muzhun` 文件夹到可写目录；不要直接在 ZIP 内运行。
3. 双击 `Start-Muzhun.cmd`。首次会创建 `.venv` 并安装处理依赖，需要联网。保留启动窗口。
4. 安装完成后自动打开本机网页。若浏览器没有打开，复制启动窗口打印的实际地址；常用端口被占用时会换端口。
5. 点击“环境检查”，再点击“字幕避让”示例。这个示例提供 SRT，无需下载语音模型。
6. 选择自己的 30–60 秒视频。没有提供 SRT 时，首次需要联网下载所选 Whisper 模型；下载失败可先改用已有 SRT。
7. 点击字幕，按“试听本句”核对原声。处理待确认纠词、保存文字修改，再检查画面位置，点击“标记已复核”。
8. 用“下一条未复核”逐句检查。重复错词用“批量改词”先预览、勾选要改的句子再应用；误改用顶部“撤销”。
9. 点击“导出视频”或“视频与字幕包”。关闭启动窗口会停止服务，已保存的结果、复核记录和撤销历史仍在 `outputs`。

字幕位置、样式和画面依据需要时再展开；匿名测试与处理记录在“测试与处理信息”中。普通用户在浏览器操作即可，使用 Skill 时由 Codex 调用同一处理环境，无需每次打开网页。

批量改词只改正文，保留原文；同时刷新画面关联与避让位置。默认完整英文词匹配保护带数字或下划线的标识符。应用后需要重新检查受影响的句子，原来其他句子的复核记录仍可保留。已复核是你填的工作记录，不是机器保证内容准确。

Ctrl + Enter（Mac 用 Command + Enter）保存当前文字与时间。切换字幕、离开任务或导出时有未保存内容，会出现“保存并继续 / 放弃修改 / 继续编辑”。撤销和重做最多保留 30 次已保存操作。

已有 Python 但未被检测到时，在项目目录运行：

```powershell
.\run.ps1 -Python '你的Python完整路径\python.exe'
```

项目位于中文或带空格目录时也可使用完整路径参数。首次下载可能受网络影响，启动器不会改系统网络设置或自动转到外部识别服务。

## macOS / Linux

需要 Python 3.10+，推荐 3.12。运行：

```sh
sh run.sh
```

需要可用中文字体。Linux 可安装 Noto Sans CJK；或用 `MUZHUN_FONT` 指定本机中文字体文件。提供了跨平台脚本和 CI 配置，但本次发布前的实际验证只在 Windows 完成；macOS / Linux 仍待运行结果。

## 配合 Codex

先完成上述安装。Windows 运行 `install-skill.ps1`；macOS / Linux 运行 `.venv/bin/python scripts/install_skill.py`。默认安装到 `CODEX_HOME/skills` 或 `~/.codex/skills`，可用 `--destination` 指定你的 Agent 支持的目录。

然后在下一条 Codex 消息写：

```text
使用 $muzhun-subtitles 处理我提供的视频，核对术语并保护讲解内容。
交付视频、可编辑字幕和复核页，列出待确认问题。
```

移动项目目录后重新安装 Skill；已有 Skill 用 `-Update`（PowerShell）或 `--update`（Python）。单独的 Skill ZIP 不包含字幕引擎和语音模型，不能代替源码安装。

## 常见问题

| 现象 | 操作 |
| --- | --- |
| 提示找不到 Python | 安装 64 位 Python 3.12；或使用 `-Python` 指定 |
| 安装依赖失败 | 阅读启动窗口最后的错误，确认网络与磁盘可用后重试 |
| 端口被占用 | 使用启动窗口新打印的地址 |
| 中文字幕字体缺失 | 安装中文字体，或设置 `MUZHUN_FONT` |
| 语音模型下载失败 | 先体验内置演示，或导入自己的 SRT；稍后重试下载 |
| 重新打开后有旧任务 | 结果保存在本机 `outputs`，这是正常行为 |
| 朋友打不开你的 127.0.0.1 地址 | 每个人需要在自己的电脑安装并启动，或以后使用另行部署的在线服务 |

环境检查只检查运行条件；“可以开始”不表示字幕内容正确。正式使用仍要听音、检查术语和字幕位置。

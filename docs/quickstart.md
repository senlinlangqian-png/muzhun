# 第一次使用幕准 1.0

幕准在自己的电脑处理视频和音频。你需要安装 Python；不需要买域名，也不需要字幕服务 API Key。

## Windows：四步开始

1. 安装 [Python 3.12 64 位](https://www.python.org/downloads/windows/)，安装时勾选 **Add python.exe to PATH**。
2. 在 [Releases](https://github.com/senlinlangqian-png/muzhun/releases) 下载 `muzhun-版本-source.zip`。右键“全部解压”，不要在压缩包内部运行。
3. 双击 **Start-Muzhun.cmd**，保留启动窗口。首次安装依赖需要联网；准备好后自动打开本地网页。若没有打开，复制窗口打印的地址。
4. 上传视频，选择语言和识别质量，点击 **自动生成字幕**。完成后试听、改字，再导出视频。

推荐先处理 30–60 秒短片，确认模型与电脑速度适合自己。直接点“字幕避让”可体验内置示例，不需要语音模型。

## 给 Agent 使用

解压完整源码后，双击 **Install-Skill.cmd**，输入 Codex / DeepSeek Harness 等工具的编号。安装器一次准备引擎、中文字体和 Skill。安装完成后重新加载对应工具的技能列表。

跨平台也可以在项目目录运行：

```sh
python scripts/setup.py --agent codex
```

其他工具把 `codex` 换成 `deepseek`、`claude`、`cursor` 等；自定义 Harness 技能目录用 `--destination`。完整例子见 [朋友试用步骤](friend-test.md)。单独的 Skill ZIP 不含运行引擎，第一次使用请选择完整源码。

## 给更长的视频自动加字幕

视频最高 **2 小时、2 GB**，音频最高 **2 小时、512 MB**。不提供 SRT 就自动识别语音；已有 SRT 可以导入，跳过语音识别。

- Small：日常均衡。Base：快速试用。Large v3 Turbo：更大的模型，下载和 CPU 识别通常更慢，需要更多内存。质量取决于素材，不保证选大模型就没有错字。
- 尽量选择正确语言。专有名词可以填进术语表；视频画面中的清晰术语也会提供识别提示。
- 音轨按短片段识别，每段保留真实时间。遇到处理错误，在原任务点 **重试**，复用已经完成的识别片段。改变文件、模型或识别设置会使用不同缓存。
- 重试会重新准备画面和音轨；这是识别片段复用，不是视频合成断点续传。
- 长视频最多抽 600 帧。两小时视频约每 12 秒一帧，快速切换的重要画面需要人工检查或手动画保护区。

长文件会占用磁盘。两小时的 16 kHz 单声道解码音轨约 230 MB，输出 MP4 的大小另计；请为源文件、缓存和导出保留空间。处理速度受 CPU、模型、分辨率和画面变化影响。

## 改字幕和歌词

视频点击字幕后可改文字、时间、样式和位置。Ctrl / Command + Enter 保存；批量改词先预览再应用；撤销和重做保留最近 30 次已保存操作。改动影响的句子需要重新复核。

音频页面选择“说话 / 课程 / 播客”或“歌曲 / 歌词”。已有歌词可以粘贴或导入 TXT / LRC / SRT。处理后点击波形定位、点“试听本句”；拆句时将文字光标放到分界处，并把播放时间定位到真正的分界。

重复副歌找错位置时，展开“拆分、合并与重新定位”，限定音频起止范围，再对齐本句。没有找到真实锚点的句子会保持未定位；不能把文字匹配分数当成时间准确率。

导出 SRT 供剪辑，LRC 供播放器显示滚动歌词，ASS 保留样式和位置，MP4 已合成可见字幕。已复核是你填写的记录，不是系统自动保证准确。

## macOS / Linux

安装 Python 3.10+（推荐 3.12），在解压目录运行：

```sh
sh run.sh
```

启动器缺少中文字体时会下载经 SHA-256 校验的 Noto Sans CJK。自定义字体用 `MUZHUN_FONT` 指定绝对路径；字体用于本机测量和合成，不放进交付包。

## 安装或识别失败

- 找不到 Python：安装 Python 3.12，重新打开启动窗口。已有 Python 可用 `run.ps1 -Python 'Python完整路径'`。
- 下载慢或失败：首次依赖、字体与模型下载受网络影响，修复网络后重新运行；不会自动改成外部云端识别。
- 文件已处理但浏览器关了：再次启动，从“最近任务 / 最近音频”继续编辑。
- 端口被占用：启动器会选下一个空闲端口，请使用窗口打印的实际地址。
- 需要排错：网页点“环境检查”；或在项目环境运行 `python -m muzhun.cli doctor --full`。在 [Issues](https://github.com/senlinlangqian-png/muzhun/issues/new/choose) 发错误信息，删除私人路径，勿提交账号或敏感素材。

关闭启动窗口会停止服务；项目 `outputs` 中已保存的任务不会删除。升级前保留旧项目和 outputs，新包完整解压后重新运行；不要把 outputs 或 .cache 上传到 GitHub。

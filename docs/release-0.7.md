# 幕准 0.7.0 公开测试候选版

本版重点完善歌词纠错后的工作流，保留视频的术语与画面联动避让。建议首次开源使用 GitHub Pre-release，先收集安装失败、错词、错位与未定位案例。

- 中文自动转录默认输出简体，识别原文与词级时间仍保存；用户提供的歌词保持原样。
- 补充正确歌词后复用保存的音频锚点重新对齐，不需要为改字重复识别。网页和 Skill 命令调用同一逻辑；更新整条时间线可以撤销，连同正文来源、时间和人工复核一起恢复。
- 简繁差异在文字匹配时统一；显式“文字转为简体”只取消实际修改行的旧复核，原文保留。
- 识别锚点可查看，新增下一句待复核与播放行提示。保存期间锁定编辑控件，避免响应覆盖正在输入的文字；调整时间后重新检查相邻重叠提示。
- 原始识别的疑似署名、外文片段和低可靠片段提示复核，不自动删词。零时长词保留为时间点线索，只有同一时间点的行仍需手动定位。
- 安装目标覆盖 Codex、Claude Code、Cursor、DeepSeek Harness、Gemini CLI、OpenCode、Kimi Code CLI，附共享目录与自定义目录入口；需要有文件和 Python 执行能力。新增三个目标完成本机隔离安装与引擎调用，完整 Agent 会话仍待试用。意见统一提交到 GitHub Issues，提供报错、建议和提问表单。

下载完整 `muzhun-0.7.0-source.zip`，解压并按 [第一次使用](quickstart.md) 启动；给朋友使用 Agent 见 [试用教程](friend-test.md)。单独 Skill ZIP 不含字幕引擎。旧 0.6 歌词任务可继续编辑，但缺少词级缓存，按纯文本重对齐需重新上传音频；也可以直接导入已有 LRC/SRT。

本机 140 项自动检查通过。源码包在本机新的中文与空格目录完成首次安装，独立 Skill 实际导出视频与 LRC；尚未代替其他设备或真实 Harness 会话验收。真实虚拟歌姬歌曲复测保留全部 33 行原歌词，当前仅 8 行通过定位条件，剩余 25 行需要手动处理；没有据此宣称时间准确或识别效果普遍提升。歌曲原词对齐明确作为实验功能，当前不是演唱专用强制对齐器，也没有逐字卡拉 OK。更多验证范围见 [验证记录](testing.md)。

公开包只含代码、说明、Skill、测试和原创合成示例。本次私有歌曲、歌词、识别记录和本机运行路径不进入发布包。完整源码、独立 Skill 和 wheel 均为本地待发布附件，发布状态以 GitHub 实际结果为准。

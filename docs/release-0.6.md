# 幕准 0.6.0 朋友试用版

本次增加音频与歌词入口，以及 DeepSeek Harness 等本地 Agent 的安装选项。

- MP3、WAV、M4A、FLAC 等音频生成逐行 LRC 与 SRT；可提供 TXT 歌词辅助对齐，或导入已有 LRC/SRT 保留时间。
- 原歌词不被自动转录覆盖，按全曲顺序匹配重复句。没有足够锚点的行保留“未定位”，补齐前不导出残缺字幕。
- 网页可逐句试听、手动设置起止、整体偏移、标记复核与撤销 / 重做。修改后取消相应旧复核标记。
- 安装选项支持 DeepSeek Harness、Codex、Claude Code、Cursor 与共享 .agents 目录；所有入口使用同一 Skill 和本机引擎。

完整源码包 `muzhun-0.6.0-source.zip` 包含示例与安装脚本；单独 Skill 包不含引擎。安装和朋友测试详见 [试用步骤](friend-test.md)。这是需要 Python 的源码版，无需购买域名。

歌词对齐是基于 ASR 文字锚点的辅助草稿，不是针对演唱训练的强制对齐模型，也没有逐字卡拉 OK 动画。实际歌曲须试听修正；受控朗读示例的运行结果不能代表歌曲准确率。验证范围见 [验证记录](testing.md)。

# 幕准 1.0.0 发布说明

幕准可以给本地视频自动加字幕，参考画面核对专业术语并避开重要区域，也可以把音频转为逐行 SRT / LRC。网页与 Agent Skill 共用同一个引擎。

## 这版的变化

- 视频从 10 分钟 / 250 MB 提升到 2 小时 / 2 GB，音频到 2 小时 / 512 MB。
- 识别按短片段分段，带重叠上下文、全局词时间与已完成片段缓存；原任务重试可以复用。
- 修复分段边界漏词，补回实际识别词并提示试听；改进混合中英文与小数断句。
- 说话和歌曲使用不同识别选项，提供语言、模型和术语入口，中文默认简体且保留原文。
- 歌词波形定位、拆句/合并/删除、撤销重做、限定音频范围重新对齐本句。
- 统一引擎与 Skill 安装，缺中文字体时下载并校验 Noto Sans CJK，字体用于实际渲染。
- 简化首页与下载说明，提供英文 README。

## 下载选哪个

| 文件 | 用途 |
| --- | --- |
| `muzhun-1.0.0-source.zip` | 首次使用推荐；解压后包含网页、引擎、安装器、Skill 和原创演示 |
| `muzhun-subtitles-skill-1.0.0.zip` | 只有 Skill；适合已经安装幕准引擎的人 |
| `muzhun-1.0.0-py3-none-any.whl` | Python 开发者使用的引擎安装包 |
| `SHA256SUMS.txt` | 核对下载文件是否完整 |

需要 Python 3.10+，推荐 Python 3.12。Windows 双击 Start-Muzhun.cmd；要装 Skill 则双击 Install-Skill.cmd。macOS / Linux 运行 sh run.sh。首次依赖与模型下载需要联网，素材处理在本机进行。

## 验证范围

本机运行自动检查、实际识别和渲染、长文件及浏览器编辑下载。两个长静音样例分别验证 11 分钟和 2 小时；连续合成朗读另有检查。具体结果、测试数量及跨平台 CI 状态以 [验证记录](testing.md) 为准。

歌曲原词对齐仍是实验功能，真实多口音、噪声、快速游戏与各 Agent 会话需要更多试用。没有独立真实数据集的通用准确率。普通词识别错、歌词未定位和画面漏检仍可能发生，请试听检查后交付。

公开源码或正式版本号不表示所有实验功能已解决。发布本版时取消 GitHub 的 Pre-release 标签；上传/标记版本只是发布动作，不能代替这些测试。

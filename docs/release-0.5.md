# 幕准 0.5.0 开源测试版

这是本地字幕工具与可安装的 Codex Agent Skill。源码、简洁网页、处理引擎、合成示例与测试一起分发；无需域名、API Key 或公网服务器。Windows 已实测，macOS / Linux 仍需实机验收。

## 本次更新

- 逐句试听、搜索筛选和人工复核队列，句末自动暂停。
- 批量改词前后对照，只应用勾选句子；改词后重新计算画面关联与避让布局。
- 人工复核对应确定的文字、时间和 C 位置，相关修改取消旧标记；其他句子的标记可保留。
- 30 步撤销 / 重做与复核记录随任务保存，重开后可恢复。待确认纠词需先采用或保留原词。
- 修订冲突提示、未保存输入提醒、导出修订标识和失败恢复；Skill 可调用同样的编辑、复核与恢复能力。

## 下载哪个文件

| 文件 | 用途 |
| --- | --- |
| `muzhun-0.5.0-source.zip` | 普通用户与开发者使用，解压后按 quickstart 启动；需要 Python |
| `muzhun-subtitles-skill-0.5.0.zip` | 仅 Skill，另需安装幕准字幕环境 |
| `muzhun-0.5.0-py3-none-any.whl` | 熟悉 Python 的用户安装引擎与网页；不含示例或 Skill |
| `SHA256SUMS.txt` | 校验三份分发文件的完整性 |

首次安装需联网下载依赖，首次语音识别下载模型。提供 SRT 或运行内置示例不需要下载语音模型。当前不是免安装 EXE。

## 第一次上传

按照 [GitHub 网页上传教程](github-upload.md)：解压源码包，只上传里面 `muzhun` 文件夹的内容。在 GitHub 创建 `muzhun` Public 仓库，然后上传；需要下载附件时再创建 `v0.5.0` Release。公开包排除本机环境、模型缓存、运行输出和用户视频。

## 验证范围

103 项自动检查；浏览器复核、批量改词、撤销恢复、未保存提醒与导出见 [验证记录](testing.md)。实际导出保留音轨与分辨率，时长差 0.007 秒；浏览器下载的 ZIP 与本机产物一致。示例为受控合成视频并提供 SRT，不能据此宣称真实用户准确率、节省时间或语音识别成绩。复核标记是操作者的工作记录，与自动估算分开保存。

推荐先公开为测试版，收集不同电脑的安装情况和真实视频结果。没有宣称全新算法、全球唯一或所有设备已验证。
